# Cube Radar: радар скрытых кубов для Aion 2

**Cube Radar** — мини-радар поверх **Aion 2 (Global)**. Он показывает, где сейчас стоят **скрытые кубы**: расстояние,
направление и высоту. Через Npcap он читает трафик сервер→клиент, как Wireshark. Память игры он не читает, в процесс
ничего не внедряет и в игру ничего не отправляет. Единственное соединение с интернетом — отключаемая проверка
обновлений на GitHub (только у готового exe).

Интерфейс по умолчанию русский. Английский включается в настройках и в веб-виде.
[Руководство](docs/ANLEITUNG.md) остаётся на немецком.

- **Мини-радар поверх игры:** скрытые кубы рядом, с расстоянием, направлением и высотой (▲ над вами, ▼ под вами),
  звук на каждый новый куб
- **Статус каждого куба:** видим, вне видимости, открывается, открыт, исчез
- **Противники на том же радаре:** красные ромбы и список с именем, фракцией, PvP-рангом и расстоянием (Global/Abyss,
  первая тестовая версия). Пять кодов ранга сверены со скриншотами; остальной предполагаемый порядок помечен `*`
- **Веб-вид** с картой, списком и своей базой точек (экспорт в CSV/JSON)
- **Один exe** для Windows 10/11, без установки, обновляется по нажатию
- Проверено в **Вертероне**; в других зонах радар узнаёт признак куба сам
  ([Где это работает?](docs/ANLEITUNG.md#7-wo-funktioniert-es))

## Скачать

Готовая сборка для Windows 10/11 (64 бита) лежит в
[**Releases**](https://github.com/AsseylumVA/aion2-cube-radar/releases/latest): скачайте `Cube.Radar.exe` и
запустите двойным щелчком. Устанавливать ничего не нужно, .NET уже внутри. Нужен [Npcap](https://npcap.com)
(установщик со стандартными параметрами). При запуске Windows спросит права администратора, чтобы оверлей видел
клавишу Alt (это можно отключить, см. ниже). Как читать мини-радар и пользоваться им — в
**[руководстве](docs/ANLEITUNG.md)** (на немецком). С версии 0.8.0 радар сам сообщает о новой версии и обновляется
по нажатию ([Обновления](docs/ANLEITUNG.md#8-updates)).

> **Внимание:** по словам автора другого инструмента, поддержка NCSOFT считает программы, которые читают данные
> игры, нарушением пользовательского соглашения. Использование — на ваш риск.

## Состав

Состояние: **фаза 3 (радар) завершена**. Скрытый куб опознан в Вертероне (шаблоны 1200039 и 1200041, радиус
рассылки ≈ 100 м). Своя позиция берётся из четырёх источников, привязанных к событиям. Все находки собраны в

## Сборка и тесты

```powershell
dotnet build CubeRadar.slnx -c Release
dotnet test CubeRadar.slnx -c Release
```

Исполняемый файл окажется в `src\CubeRadar.Cli\bin\Release\net10.0-windows\cuberadar.exe`. Короче: `.\cuberadar.cmd`.

## Публикация новой версии

Exe собирает и публикует сам GitHub ([`.github/workflows/release.yml`](.github/workflows/release.yml)):

1. Поднимите `<Version>` в `src/CubeRadar.Cli/CubeRadar.Cli.csproj` и `src/CubeRadar.Core/CubeRadar.Core.csproj`,
   закоммитьте и отправьте.
2. Создайте тег с описанием и отправьте его:
   ```powershell
   git tag -a v0.8.1 -m "- Что нового, по пункту на строку"
   git push origin v0.8.1
   ```
   Описание тега становится в релизе блоком «Что нового в 0.8.1». Без описания там окажутся темы коммитов с прошлого
   тега.
3. Action проверяет, что тег совпадает с версией, гоняет тесты, собирает `Cube Radar.exe` и публикует релиз с
   `Cube.Radar.exe` и контрольной суммой. Уже запущенный радар сообщит об обновлении при следующем старте или в
   течение 6 часов.

Ту же сборку локально делает `tools\package.ps1`. Если exe уже запущен, его сначала просят завершиться через `--quit`.

## Радар

**Одним файлом, чтобы передать:** `powershell -File tools\package.ps1` собирает `dist\Cube Radar.exe`.
- В файле уже есть .NET, веб-интерфейс и конфигурация по умолчанию. Двойной щелчок сразу открывает оверлей, без
  консоли.
- Данные (записи, база, настройки, журнал) лежат в `%LOCALAPPDATA%\CubeRadar`.
- Свой файл конфигурации в `%LOCALAPPDATA%\CubeRadar\config\` (например `radar.json` с новыми опкодами после патча)
  важнее встроенного.
- Значок программы делает `tools\make_icon.ps1` (`assets\cuberadar.ico`).

Из репозитория:

```powershell
.\cuberadar.cmd radar      # полный вид: браузер + оверлей + консоль
.\overlay.cmd              # только оверлей: без браузера и консоли, значок в трее
```

**Режим только оверлея** (`overlay.cmd` или `radar --overlay-only`):
- Программа работает в фоне и на экране не видна. Виден только мини-радар поверх игры.
- Правый щелчок по значку в трее: Настройки (то же по двойному щелчку), оверлей вкл/выкл, масштаб,
  «Открыть веб-вид» и «Выход».
- **Настройки** открываются кнопкой ⚙ справа сверху на оверлее или из трея. Изменения действуют сразу и
  сохраняются:
  - звук вкл/выкл с кнопкой «Проверить», громкость (при движении ползунка звук слышно) и по желанию свой файл .wav.
    С момента запуска «Cube Radar» — отдельное приложение в микшере громкости Windows, не «системные звуки».
  - масштаб, размер (75–150 %) и прозрачность, отдельно для радара и для списка имён противников под ним
  - север
  - «Только когда Aion 2 на переднем плане» и «Скрывать в меню»
  - кнопки: сбросить положение, открыть веб-вид, завершить радар
- Вывод пишется в `captures\radar_<дата_время>\radar.log`. Запись, база, сигнал и горячие клавиши меток работают
  как обычно.

Полный вид открывает в браузере `http://127.0.0.1:5313`.
- **Радар** показывает местность вокруг вас (север сверху, кольца, дальность видимости ≈ 100 м пунктиром).
- **Высота:** ▲ = куб над вами, ▼ = под вами, ■ = та же высота (± 3 м). Полоса высоты справа на радаре берёт вашу
  высоту за среднюю линию. В списке пишется «▲ 38 м над вами» и так далее. Если позиции больше 5 с, рядом указан её
  возраст.
- **Карта** показывает все кубы, ваш след и, если они есть, возможные точки зоны.
- **Список:** дистанция, сторона света, разница высот, «замечен … назад», «существует …» и статус. Статусы:
  видим, вне видимости (скорее всего ещё стоит), открывается, открыт (вами или игроком N), исчез.
- **«Звук вкл» и «Уведомления вкл»** в браузере дают звук или уведомление на каждый новый куб. Консоль пищит
  дополнительно (отключается флагом `--no-beep`).
- **Своя позиция** приходит только по событиям, например когда вы накладываете бафф или когда вас атакуют. В шапке
  видно, насколько она стара. Без свежей позиции радар показывает оценку с кругом неопределённости.
- **Мини-радар поверх игры (оверлей):** небольшое окно всегда сверху и никогда не забирает фокус у игры.
  - Содержимое: север сверху, вы в центре, кольца, дальность видимости (~100 м) пунктиром и недавний след. След
    показывает, откуда вы пришли: игра не присылает направление взгляда.
  - Кубы рисуются как ▲/▼/■ (над вами, под вами или на вашей высоте) с подписью «86 m ▲38». Куб за пределами
    масштаба — указатель » на ободе, в его сторону.
  - В шапке — возраст вашей позиции и масштаб.
  - **Перемещение:** `Ctrl+Shift+F11` открывает настройки. Пока они открыты, оверлей остаётся видимым и его можно
    перетащить мышью. Положение сохраняется, когда кнопку отпускают.
  - **Масштаб:** `Ctrl+Shift+F12` или колесо мыши над оверлеем при открытых настройках (60 / 120 / 250 м).
  - **Сам появляется и прячется:** виден, только когда Aion 2 — активное окно. Пока виден курсор (меню, режим
    интерфейса), оверлей тоже прячется, даже если курсор стоит на месте, и не закрывает меню. Исключение: пока
    удерживается `Alt` (тогда Aion 2 показывает курсор), оверлей остаётся, пока клавишу не отпустят.
    - Что `Alt` нажат, видно только с правами администратора. Сама Aion 2 запущена с ними, и Windows тогда скрывает
      состояние клавиш от программ без этих прав. Поэтому оверлей один раз перезапускается с правами администратора
      (запрос UAC). Если отказаться, он продолжит работу без них, и `Alt` будет прятать его, как меню. Браузер и
      проводник он всё равно открывает без прав администратора.
    - Для этого читается только состояние окна, курсора и клавиш Windows, ничего из игры.
    - Без запущенной игры (повтор записи) он виден всегда.
    - Прятание в меню отключается в `data\settings.json` ключом `"OverlayHideInMenus": false`, перезапуск с правами
      администратора — ключом `"OverlayAdminRights": false` (оба пункта есть и в настройках).
  - `Ctrl+Shift+F10` полностью выключает его и включает снова.
  - Игра должна быть в оконном или безрамочном полноэкранном режиме. Поверх исключительного полноэкранного режима
    нарисовать ничего нельзя.
  - Отключается флагом `--no-overlay`.
- **Север:** в конфигурации север — мировая ось −Y (не подтверждено). Если направление не совпадает с миникартой,
  смените его сверху в пункте «Север». Выбор действует и на оверлей и сохраняется в `data\settings.json`.
- **Запись:** каждая сессия пишет `captures\radar_<дата_время>\raw.pcapng` и `markers.jsonl`. Горячие клавиши из
  следующего раздела работают и здесь.
- **База:** каждое наблюдение попадает в `data\radar.db`. Экспорт — ссылками «CSV» и «JSON» в списке.
- **Самопроверка:** если ожидаемые пакеты перестают приходить (например после патча), появляется красное
  предупреждение. Опкоды лежат в `config\radar.json`.
- **Другие зоны:** если объект открывают ключом куба или он стоит точно на известной точке, радар запоминает его
  шаблон как шаблон куба.

Повтор для проверки: `.\cuberadar.cmd radar --replay captures\<сессия>\raw.pcapng --speed 5`. С `--stop-at 200`
повтор останавливается на 200-й секунде записи.

### Фракция противников и PvP-/Abyss-ранги (тест)

С версии **0.9.0**. При переходе со старого exe эту версию один раз нужно скачать вручную из этого репозитория:
более ранние сборки могут всё ещё проверять обновления в исходном репозитории. С 0.9.0 проверка смотрит сюда.

Для элийцев: `.\cuberadar.cmd radar --overlay-only --faction Elyos`.
Выбор сохраняется. Сменить его можно в **⚙ → Противники → Своя фракция** или в веб-виде в пункте **«Я играю»**.
«Автоматически» ждёт пакет своего персонажа; если радар запущен посреди сессии, пакета ещё может не быть. Для
асмодиан — `--faction Asmodian`.

- Противниками считаются только игроки уверенно распознанной враждебной фракции. Привязки по entity id или серверу
  не угадываются.
- Красные ромбы показывают свежие позиции. Под ними — трое ближайших противников с фракцией и рангом.
- С **0.9.1** класс солдата **1–9 рисуется внутри ромба**, **T** — новобранец (Trainee), **?** — неизвестно.
  Имя и расстояние стоят рядом. В списке остаётся полный ранг и звёздочка предположения.
- 19 = Trainee, 17 = Eighth-Class Soldier, 16 = Seventh-Class Soldier, 15 = Sixth-Class Soldier и
  14 = Fifth-Class Soldier отмечены на скриншотах. Остальной счёт
  (18 = Ninth-Class Soldier … 10 = First-Class Soldier; меньший код — более высокий ранг) — **предположение** (`*`).
- Неизвестные варианты пакета показывают **«ранг неизвестен»**. Веб-профили не запрашиваются.
- Координаты могут приходить с задержкой. Через 10 с без обновления позиции живая точка пропадает. В списке старые
  позиции помечены. Ушедшие и убитые противники, а также контакты до телепорта, отбрасываются.
- Если своя позиция стара или оценена, направление и расстояние тоже неточны. У расстояния тогда стоит `~`/`≈`.
- В ⚙ дополнительный показ противников можно выключить. Кубы при этом остаются.

Соответствие рангов, если код удалось прочитать из поддерживаемого варианта пакета:

| Код | PvP-/Abyss-ранг | В значке |
|---:|---|:---:|
| 19 | Trainee | T |
| 18 | Ninth-Class Soldier * | 9 |
| 17 | Eighth-Class Soldier | 8 |
| 16 | Seventh-Class Soldier | 7 |
| 15 | Sixth-Class Soldier | 6 |
| 14 | Fifth-Class Soldier | 5 |
| 13 | Fourth-Class Soldier * | 4 |
| 12 | Third-Class Soldier * | 3 |
| 11 | Second-Class Soldier * | 2 |
| 10 | First-Class Soldier * | 1 |

`*` = выведено из опубликованного порядка счёта, отдельным скриншотом ещё не подтверждено.

## Запись

```powershell
.\cuberadar.cmd dump live              # до "q" + Enter или Ctrl+C
.\cuberadar.cmd dump live --seconds 120
```

Каждая запись попадает в `captures\<дата_время>\`:
- `raw.pcapng`: сырые пакеты для повтора и Wireshark
- `frames.jsonl`: каждый разобранный кадр
- `markers.jsonl`: поставленные метки
- `census.json` и `census.txt`: перепись опкодов и здоровье потока

**Метки** (на каждую клавишу — звук подтверждения):

| Горячая клавиша (глобально, в том числе в игре) | Метка |
|---|---|
| Ctrl+Shift+F5 | `cube_visible` (куб виден) |
| Ctrl+Shift+F6 | `cube_opened` (куб открыт) |
| Ctrl+Shift+F7 | `cube_out_of_sight` (куб вне видимости) |
| Ctrl+Shift+F8 | `cube_back` (снова в видимости) |
| Ctrl+Shift+F9 | `note` (общая метка) |

В консоли Enter ставит метку, по желанию с текстом. `1`–`5` соответствуют горячим клавишам, `q` заканчивает запись.
Другие клавиши задаются так: `--hotkeys "ctrl+alt+F1=cube_visible,…"`.

## Разбор

```powershell
.\cuberadar.cmd dump captures\<сессия>\raw.pcapng     # повтор -> raw.replay.jsonl (+ подмешивается markers.jsonl)
.\cuberadar.cmd census captures\<сессия>\raw.pcapng
python tools\census.py captures\<сессия>\frames.jsonl
python tools\crosscheck.py captures\<сессия>\raw.pcapng captures\<сессия>\frames.jsonl
```

### frames.jsonl

В каждой строке один JSON-объект. `t` — миллисекунды Unix: для пакетов часы захвата, для меток — часы компьютера.

- `frame`: `n` (порядковый номер), `t`, `flow`, `src` (`top` | `lz4` | `emb`), `depth`, `path`, `op` (байты на проводе
  в hex), `name`, `len` (тело), `wire` (кадр вместе с varint), `flag` (необязательно) и `hex` (тело без опкода).
  - `path` описывает вложенность: `B3.0/B4.2` — третий кадр в связке 4, а связка 4 сама является первым кадром
    связки 3. `E7.0` — связка, вложенная в тело другого пакета.
- `bundle`: `id`, `src`, `depth`, `path`, `host`, `raw`, `zlen`, `out`, `ok`
- `marker`: `t`, `local`, `label`, `text`, `via`
- также `session`, `flow`, `gap`, `stats`
